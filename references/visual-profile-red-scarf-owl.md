# Red Scarf Owl Collage Visual Profile

## Purpose

这是一个可复用、可显式调用的视觉 Profile，用于知识图解、公众号文章配图和个人 AI 产品实践内容。

调用方式：

```text
使用“红围巾猫头鹰拼贴”视觉配置。
```

本 Profile 只替换当前视觉主题，不改变内容研究、结构、中文可读性、系列一致性和 QA 规则。

## Fixed character identity

主角是一只偏写实、带编辑拼贴质感的猫头鹰，代表作者、产品经理、个人开发者或项目负责人。

固定特征：

- 白色面部，棕黑色斑点羽毛，黄色眼睛；
- 始终佩戴有真实布料纹理的红色围巾；
- 默认穿橄榄绿色或低饱和军绿色外套，衣服可随场景小幅变化，但不能破坏角色识别；
- 角色气质是专注、思考、检查、发现问题和推进工作，不做儿童吉祥物式卖萌；
- 猫头鹰身体和羽毛保持偏写实，手臂采用明显的火柴人语言，形成“写实猫头鹰 + 图解式手臂”的固定反差。

### Hands and arms — hard rule

操作电脑、纸张、笔、文件、印章或其他工具时：

- 必须使用纯黑色、简洁的火柴人风格手臂；
- 手臂为实心或粗线黑色，不使用骨骼结构；
- 手掌和手指同样为纯黑色，保持正常可读的粗细，可以自然拿笔、指向、翻页、敲键盘；
- 手掌不能过细，也不能像白色骨架手；
- 禁止使用骨架手、骷髅手、白色骨骼手；
- 禁止把猫头鹰翅膀直接当成人类手臂或手掌使用。

## Visual language

整体为“编辑杂志拼贴 × 现实工作台 × 手写批注”，不是企业信息图。

- 暖白、浅米色纸张背景；
- 背景允许轻微纸张纤维、印刷颗粒和少量旧纸质感，但保持干净；
- 禁止大面积脏污、重度斑驳墙面、发霉感或满屏噪点；
- 画面可以有丰富物件，但必须有清楚主次，主体、核心信息、辅助材料分层明确；
- 人物、文件、设备和主要物件可带撕纸轮廓、剪贴白边和轻微纸张阴影；
- 使用真实物件与图解信息混合，而不是把所有信息塞进统一卡片。

### Preferred physical objects

可反复使用：

- 旧电脑或普通笔记本电脑；
- 项目文件、PRD、测试报告、便签、文件夹、档案盒；
- 笔记本、钢笔、尺子、回形针、图钉、胶带、印章；
- 录音机、磁带、录音波形或会议材料；
- 咖啡杯、植物和桌面工作物件；
- AI 对话窗口、代码片段、版本记录可以作为被剪贴进画面的材料，而不是主体 UI。

## Typography and annotation

- 大标题：粗粝红色笔刷、丝网印刷或剪贴字效果；
- 批注：钴蓝或深蓝手写字，搭配箭头、圈画、星号、下划线和问号；
- 信息纸片：橄榄绿色为主要承托色；
- 正文线稿：墨黑、深灰；
- 少量警示红或橙只用于风险、失败或关键转折；
- 长段中文尽量使用确定性排版，不依赖图像模型直接生成；
- 若图像模型直接生成中文，交付前必须逐字检查，不得保留错字、乱码、伪文字或错误标点。

## Composition

- 每张图只承担一个核心关系或一个主要问题；
- 可以信息丰富，但必须能在缩略图中看见一个明确主体和一条主要阅读路径；
- 角色通常占据中部或一侧的视觉重心，不能被缩成角落装饰；
- 信息通过纸张、档案、工作台、箭头与批注组织，不采用标准 SaaS 卡片网格；
- 墙面或背景只承担气氛，不作为主要信息层，不用大量斑驳纹理抢主体；
- 系列图保持同一猫头鹰脸型、羽毛、眼睛、围巾、外套基调、黑色手臂语言和纸张质感。

## Workflow for locking the character

角色和视觉配置不能在第一次生成时直接永久固化。

必须按以下顺序：

1. 先生成一张完整样稿，包含主体角色、真实场景、主要信息和预期文字层级；
2. 根据用户反馈只修改被点名的维度，例如背景干净度、手臂结构、信息量、角色比例；
3. 已确认的部分必须锁定，局部修改时禁止顺手重做角色、配色、构图逻辑或信息内容；
4. 用户明确确认整体风格后，再批量生成同系列其余图片；
5. 整组图片稳定后，才将最终角色形象视为固定角色标准；
6. 后续系列可以改变动作、场景和道具，但脸部、羽毛、黄色眼睛、红围巾、黑色火柴人手臂和整体拼贴语言保持一致。

## Information completeness rule

用户确认的信息不能因为画面变干净而被随意删减。

当用户要求“背景干净一点”“墙不要那么斑驳”时：

- 只减少背景噪声、污迹和无意义纹理；
- 保留已经确认的项目文件、对话窗口、旧方案、待确认事项、工作流、测试证据、现实物件和批注层；
- 信息精简必须基于内容优先级，而不是为了获得空白而丢掉重要信息。

## Explicit avoid list

禁止：

- SaaS 圆角卡片式企业信息图；
- 蓝绿橙三色的咨询公司 PPT 或产品汇报页；
- 扁平矢量人物、统一线性图标；
- 玻璃拟态、科技渐变、赛博朋克、霓虹发光、复杂 3D 商业插图；
- 股票广告或商业宣传片式精修；
- 过度规整的等宽模块网格；
- 满墙污渍、过度泛黄、严重斑驳和脏乱背景；
- 骨架手、白骨手、过细手臂、翅膀当手；
- 为了“干净”而删掉已经确认的重要信息；
- 用户只要求排版、背景或局部元素修改时，重新设计整套风格。

## Current approved balance

当前确认的平衡是：

- 比最初高密度版本更干净，背景墙不重度斑驳；
- 比极简版本保留更多真实工作材料和信息层；
- 信息丰富但主次明确；
- 猫头鹰角色清晰居中或作为明显主角；
- 手臂与手掌为纯黑火柴人风格；
- 保留红色标题、蓝色批注、橄榄绿纸片、撕纸白边与现实工作物件。
